# JAVIRU Online Store

A responsive, mobile-first starter storefront for JAVIRU.

## Features
- Responsive shop homepage and product cards
- Product search and category filters
- Shopping bag with quantity controls and browser local storage
- Delivery details form that exports an order summary
- Nigerian naira price formatting

## Publish with GitHub Pages
1. Open the repository Settings.
2. Select **Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Choose the default branch and **/(root)**, then Save.
5. Wait for the Pages deployment to finish.

## Important before accepting real orders
This is a front-end demo. The displayed products and prices are sample content. Checkout only downloads an order-summary text file; it does not charge customers or send orders to the store. Replace sample items and connect a secure backend, a payment provider (for example Paystack), shipping rules, and a real order destination before selling. Never put secret payment keys in frontend code.
